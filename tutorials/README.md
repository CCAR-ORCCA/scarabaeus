# Scarabaeus Tutorials
This directory contains tutorials written as Jupyter Notebooks to illustrate different use cases for Scarabaeus. They are also available to view online at [Scarabaeus Examples](https://ccar-orcca.github.io/scarabaeus-docs/examples/examples_frontpage.html).

> **NOTE:**
> some tutorials require additional files not hosted on the repository. Tutorials that need one or more of these files will automatically check for their existence under `tutorials/supplmentary/` and prompt you to download them if they are missing. See the [Tutorials Primer](https://ccar-orcca.github.io/scarabaeus-docs/examples/tuts_setup.html#tuts-setup) for more info.

If you are struggling to use a Notebook in VSCode, see https://code.visualstudio.com/docs/datascience/jupyter-notebooks for more.
